# Delivery record — phases 1 through 4

## Phase 1 — Foundation
- Next.js + React + TypeScript App Router
- Tailwind v4 PostCSS setup
- Static export enabled, trailing slash URLs for static hosts
- Environment-driven canonical domain and guarded search indexing
- ESLint, TypeScript, npm commands, gitignore

## Phase 2 — Design system
- Responsive container, spacing, colors, typography and buttons
- Shared header, logo, footer, page heroes, section headings, CTA banner
- Sticky header, responsive mobile menu with Escape-key support
- Keyboard focus outlines and reduced-motion support
- Original CSS-led dashboard artwork; no external font/CDN dependencies

## Phase 3 — Homepage
- Hero copy, architecture illustration and dual CTAs
- Specialties band
- Six service cards
- Engineering principles and approach
- Three clearly labeled solution concepts
- Technology stack summary
- Four-step process and final contact CTA

## Phase 4 — Company and service pages
- Services listing and six static service detail routes
- Each service has specific SEO metadata, outcomes, capabilities, deliverables and related service links
- Industries with example challenges and solution areas
- About page focused on engineering principles
- Four-stage process page and engagement approaches
- Contact page with direct business email (configured placeholder)
- Draft privacy policy and custom 404

## Explicitly outside this delivery
- Verified client case studies and blog (phase 5)
- Detailed SEO research, keyword-volume validation, analytics integration, legal review (phase 6)
- Full automated browser/performance/accessibility verification (phase 7)
- Publishing the live Cloudflare site or buying a domain (phase 8)
- Backend, database, authentication or AI chatbot

## Source validation
TS/TSX source files checked with TypeScript parser; no syntax errors. npm registry unreachable in creation environment, so dependency installation and a production build still require verification on the recipient's computer.
